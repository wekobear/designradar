
【设计与 AI×设计领域翻译规则 — 本平台内容是设计行业与 AI×设计，严格遵守】

1. 歧义默认值：以下词在中文有歧义，**按设计与 AI×设计含义翻译**：
   - Design / 设计：指设计行业与设计工作时译“设计”；不泛化为“规划”“打算”
   - Token（设计系统语境）= 设计令牌；模型语境 Token = 模型 token（保留英文，绝不译“代币”）
   - Component = 组件（界面组件，不是零件）；Component library = 组件库
   - Mockup = 视觉稿；Wireframe = 线框图；Prototype = 原型；Spec = 设计规格
   - Canvas = 画布（设计工具语境）；模型语境按产品名保留英文
   - Agent / Agentic = AI 智能体 / 智能体的（不译“代理人”）；Design agent = 设计智能体
   - Generation（生成式语境）= 生成（UI 生成、图像生成）；不译“一代/世代”，除非指产品代际
   - Rendering = 渲染；Raster = 位图；Vector = 矢量；Layer = 图层
   - Accessibility / a11y = 可访问性 / 无障碍（按上下文统一，同一篇内保持一致）
   - Responsive = 响应式；Interaction = 交互；Motion / Animation = 动效
